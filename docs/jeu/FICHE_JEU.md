## Notions du code
- **Jamais un montant des autres (v20.26 + serveur V73, Théo 24/11)** : le serveur remet à l'échelle les euros de chaque pilote autre que « moi » (admin = Théo compris) et les marque `prive` ; l'appli n'affiche pour eux que des % (`estPrive`, `eurDe`), pas de saisie ni d'annulation pour eux. Test : `node outils-tests/teuros.js` (lit la vraie fonction `vsMasquerMontants_` dans app_scripts). Limite connue et acceptée par Théo (24/11) : avec des versements ronds, un curieux qui lit les données brutes peut deviner l'échelle.
- **Liaison avec les fichiers des amis (décision de Théo, 24/11)** : après transfert, leur script est figé (plus de mise à jour). Le serveur Versus doit donc **toujours accepter** leurs appels tels quels (`importPatrimoine`, `liaisonPatrimoine` et leurs champs, adresse `/exec` officielle inchangée) : on peut ajouter des choses, jamais en retirer ni en renommer.
- **Relevé automatique de fin de mois protégé (V74, audit B2/B8/C3, 24/11)** : une enveloppe ouverte à « — » ou vide, ou une variation de plus de 25 % sur le mois, arrête l'import (rien d'écrit, mail à Théo + onglet Bugs) ; 90 min après l'import, `vsVerifierReleves` signale tout relevé automatique manquant ; le premier million n'est jamais posé sur la seule parole d'un fichier. Le joueur saisit alors son relevé dans l'appli (« Enregistrer quand même » au-delà de 25 %). Test : `node outils-tests/timport.js` (vrai code serveur, faux Sheet). Mise en ligne du script commun chez Clément et Devlin : pas faite (refusée par la sécurité de la session) ; le serveur protège déjà le classement.
- **Relevés du mois (v20.29 + V75, Théo 24/11)** : sous le relevé dans « + », pour chaque pilote ✅ import auto / ✍️ saisi / ⏳ pas encore arrivé (jamais de montant) ; avec la clé admin, « 🔔 Le rappeler » sur un relevé manquant → bulle dans l'appli du joueur (`monRappel`), effacée dès que le relevé arrive. Test : `node outils-tests/trelevesmois.js`.
- **Suspense (v20.30, Théo 24/11)** : tant qu'un mois n'est pas complet, rien de ce mois ne se voit (`voilerMoisIncomplet`, js/2-jeu.js : à la réception de D, les colonnes calculées du mois incomplet sont vidées ; copie brute dans `D_BRUT` pour la saisie, le journal et Moi ; `D.attenteMois` = qui on attend). Test : `node outils-tests/tsuspense.js`. Limite : le serveur envoie encore les % du mois (visibles avec les outils du navigateur).
- Calcul des points partagé avec le serveur : `app_scripts/outils/extraire-podium.js` régénère `versus/PodiumCommun.js`. Changer une règle de score ⇒ remettre le serveur en ligne.
- Cartes 2D : peintres `PEINTS[clé]` dans `piste.js` (`peindre` = carte 2D, `deco` = décor 3D). Après toute retouche d'un peintre : `node outils-tests/cuire-cartes.js` (fonds `img/cartes/*.webp`) puis publier.
- Décors 3D (Théo, 24/11, pour TOUS les circuits, présents et à venir) : les gestes de la Visite sont dans le moteur commun (`piste.js`), jamais par circuit. Vue d'ensemble : glisser = tourner, pincer = zoomer. Zoomé (zoom < `ZOOM_EXPLO` = 0,75) : glisser = déplacer (le décor suit le doigt), deux doigts = zoom + pivot, joystick en bas au centre (remonte au-dessus de la jauge/énigme de la chasse au trésor), plus de rotation automatique. Changer un nombre de doigts ne fait jamais sauter la caméra (v20.32). Test : `outils-tests/tnavig.js` et `tzoom.js`. Un détail caché doit rester trouvable avec ces gestes.
- Sons : `js/sons.js` (Web Audio synthétisé, aucune note de film). Vues Carte / Visite / Hélico + plein écran.
- Aperçus admin : « 🗺️ Circuits 2027 », « 🔥 Voir décembre », « Tout afficher » (saison simulée).
